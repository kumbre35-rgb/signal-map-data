# signal-map-data

The channel database for Signal Map, as plain JSON in git. Apps fetch it through
jsDelivr's CDN, so **editing a file here updates every installed app on its next
launch** — no app release, no store review.

## Layout

```
manifest.json          generated by CI — do not edit
catalog/<CC>.json      channels for one country (ISO code), one channel per line
catalog/GLOBAL.json    channels with no country
region/<CC>.json       per-country overrides: hide dead channels, prefer a stream
scripts/               validate · build manifest · import from a running server
```

## Editing

**Replace a dead link** — open `catalog/<CC>.json`, find the channel, change the
`u` in its `streams`. Or add a second stream so the app has a fallback:

```json
{"id":"iptv:GeoNews.pk@SD","n":"Geo News","c":"PK", ...,
 "streams":[{"u":"https://new.example/geo.m3u8"},{"u":"https://old.example/geo.m3u8"}]}
```

A stream can carry `"ua"` (User-Agent) and `"ref"` (Referer) if the source needs them.

**Add a channel** — add a line to the country file. Required: `id` (unique), `n`,
`c` (must match the filename), `streams` (`[]` for embed-only). Optional: `la`/`lo`
for the map, `cat`, `lang`, `logo`, `web`.

**Remove a channel** — delete its line. Apps drop ids that disappear.

**Region-specific** — create `region/PK.json`:

```json
{ "dead": ["iptv:Blocked.us@SD"], "prefer": { "iptv:Geo.pk@SD": 1 } }
```

`dead` hides those channels in that country; `prefer` says which stream index to
try first there. See `region/_EXAMPLE.json`.

Commit to `main`. CI validates (a typo fails the build instead of breaking apps),
rebuilds `manifest.json`, and purges the CDN. Live within about a minute.

## What the app fetches

1. `https://cdn.jsdelivr.net/gh/kumbre35-rgb/signal-map-data@main/manifest.json`
   — ~5 KB. Send `If-None-Match`; a `304` means nothing changed, stop here.
2. For each entry in `chunks` whose hash differs from the local copy:
   `<base>catalog/<CC>.json` — only the countries the user actually views.
3. `<base>region/<CC>.json` for the user's country, when its hash changed.

`base` is pinned to a commit, so chunk URLs are immutable and cached forever
on the CDN. Only the manifest is ever refetched.

## Refreshing from the aggregator

With the Signal Map server running locally:

```
npm run import        # rewrites catalog/ from http://127.0.0.1:4200/api/tv
npm run validate
git diff --stat       # review what changed, then commit
```

Output is sorted by id, so the diff shows only real link changes.
